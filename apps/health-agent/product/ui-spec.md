# Health Agent UI 规范

## UI 总方向

产品首页应是 `Today Health Home`，不是指标 Dashboard，也不是 Prompt 启动器。

第一屏需要回答：

```text
我今天怎么样？
为什么？
我现在可以看什么或做什么？
需要时，ECG 能不能帮我看得更深？
```

## 信息架构

建议底部 Tab：

- 今日
- 探索
- 心脏
- 报告
- 我的

对应英文可保留在代码或国际化键中：

- Today
- Explore
- Heart
- Reports
- Me

## 今日首页结构

首页分为五个区域：

1. 顶部状态栏：日期、Apple Health 同步状态、头像、权限状态
2. 今日健康 Hero：整体身体状态和主要驱动因素
3. Agent 发现：一到两个有意义的发现
4. 健康模块：睡眠、恢复、心脏、运动、异常
5. 智能探索：洞察 chips 和健康输入框

## 第一屏线框

```text
今日
5 月 1 日 · Apple Health 已同步

今日身体状态
偏弱
Recovery 62

睡眠不足 · HRV 下降 · 静息心率略高

[查看原因] [今日建议]

Agent 发现
过去 7 天，你的睡眠减少，同时运动负荷上升，恢复指标同步走弱。
[为什么？] [看时间线]

今日模块
[睡眠 6h12m] [心脏 稳定]
[恢复 偏弱]  [运动 偏高]

继续探索
[为什么这周状态差？]
[睡眠影响心脏状态吗？]
[运动是不是太多了？]

问问你的健康数据...
```

## 今日健康 Hero

Hero 卡片字段：

- 整体状态：良好 / 正常 / 偏弱 / 建议关注 / 数据不足
- 组合分数：恢复分或今日状态分
- 主要驱动因素：睡眠、HRV、静息心率、活动、运动负荷
- 主操作：查看原因、生成今日建议
- 数据可信度：数据充分 / 部分数据 / 缺少关键数据

示例：

```text
今日状态
偏弱
Recovery 62

HRV -12%
睡眠 -42m
静息心率 +4 bpm

主要原因：睡眠减少 + 运动负荷上升
[查看完整分析]
```

## 洞察按钮

洞察按钮不是普通功能按钮，而是 Health Agent 快捷指令。

每个按钮包含：

- 问题标题
- 数据摘要
- 状态标签
- 数据来源
- 推荐优先级视觉
- ECG 增强标识，可选

示例：

```text
我最近恢复得好吗？
HRV 下降 · 静息心率略高
相关数据：睡眠 / HRV / 心率 / 运动
建议查看
```

按钮状态：

- 普通
- 新发现
- 建议查看
- ECG 增强可用
- 权限不足
- 用户固定
- 低置信度或数据不足

长按操作：

- 编辑这个洞察按钮
- 固定到今日首页
- 隐藏
- 更改默认展示风格
- 更改时间范围
- 更改触发条件

## 动态分析页

每个分析页保持稳定骨架：

1. 用户问题
2. 直接答案
3. 关键证据
4. 数据可视化
5. 解释逻辑
6. 下一步问题
7. 数据来源和置信度

Agent 可以动态决定：

- 使用哪些指标
- 展示哪些组件
- 组件顺序
- 解释深浅
- 是否插入 ECG
- 使用哪种 UI 风格

## UI 风格模式

MVP 支持：

- 结论优先：结论、证据、图表、下一步
- 图表模式：趋势图、对比图、异常点
- 时间线模式：按日期展示睡眠、HRV、心率、运动、ECG 事件

后续可扩展：

- 极简模式
- 报告模式
- 专业 ECG / 量化模式

## ECG 在 UI 中的位置

ECG 是事件增强层，不是首页默认结构。

无 ECG 时，心脏页使用：

- 静息心率
- HRV
- 日内心率变化
- 高低心率事件
- 睡眠
- 运动
- 血氧和呼吸，可用时加入

有 ECG 时，页面插入：

- ECG 事件卡
- ECG 信号质量
- ECG 波形
- 节律稳定性
- Apple 分类解释
- 自研观察点
- ECG 前后上下文

## ECG 详情页

分三层展示。

### 普通用户层

- 主要观察
- 信号质量
- 平均心率
- 节律稳定性
- 非诊断提醒
- 建议下一步

### 证据层

- ECG 波形
- RR 间期图
- Apple 分类
- 睡眠、HRV、心率上下文

### 专业层

默认折叠：

- RR interval variation
- QRS duration estimate
- QT / QTc estimate
- Noise level
- Baseline wander
- Beat classification

## 关键页面

### 恢复页

回答：

> 我最近是不是累了？恢复得好吗？

组件：

- 恢复结论卡
- HRV 趋势
- 静息心率趋势
- 睡眠和运动时间线
- 关键异常日期
- 下一步问题

### 心脏状态页

回答：

> 最近心脏状态稳定吗？

组件：

- 心脏状态概览
- 心率趋势
- HRV 趋势
- 高低心率事件
- ECG 事件，有数据时出现
- 睡眠和运动上下文
- 下一步问题

### 异常中心

每个异常都变成可点击问题：

```text
静息心率连续 4 天偏高
可能相关：睡眠减少、运动负荷增加
[查看原因]
```

### 关系探索页

示例问题：

> 运动对睡眠有帮助吗？

组件：

- 结论卡
- 运动日和非运动日对比
- 散点图
- 时间线样本
- 下一步问题

## 新用户引导

第一步：选择关注方向：

- 睡眠
- 恢复
- 心脏
- 运动
- 压力代理
- ECG
- 体重
- 整体健康

第二步：根据选择渐进式请求 HealthKit 权限。

第三步：生成第一批洞察按钮。

第四步：选择 UI 偏好：

- 简单结论
- 图表多一点
- 像报告一样
- 按时间线复盘
- 专业数据模式

## 权限不足时的体验

不要显示空页面，而要解释“解锁这个问题需要什么”。

示例：

```text
我最近恢复得好吗？

还需要 2 类数据：
- HRV
- 睡眠

授权后可以分析：
- 最近恢复趋势
- 睡眠是否影响恢复
- 运动后是否恢复充分

[授权健康数据]
```

## 文案语气

整体应冷静、可信、不制造焦虑。

推荐：

- 今天恢复偏弱。主要和睡眠减少、运动负荷上升有关。
- 最近心率略高，建议查看影响因素。
- 这次数据中有值得关注的心律相关信号。

避免：

- 恐吓式标签
- 诊断式语言
- 默认层展示过密医学术语
