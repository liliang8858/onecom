# UI 图片生成计划

## 生成目标

使用 `$imagegen` 生成一组高质量 iOS App UI Mockup，用于指导 Health Agent 的 SwiftUI 实现。

## 输出目录

```text
apps/health-agent/product/ui/mockups/
apps/health-agent/product/ui/assets/
```

## 页面清单

| 文件名 | 页面 | 核心目的 |
| --- | --- | --- |
| `today-home.png` | 今日首页 | 定义 App 第一印象 |
| `recovery-insight.png` | 恢复分析页 | 展示动态洞察页骨架 |
| `sleep-insight.png` | 睡眠分析页 | 展示睡眠结构和夜间指标 |
| `heart-status.png` | 心脏状态页 | 展示心脏连续数据和 ECG 增强入口 |
| `ecg-detail.png` | ECG 解读页 | 展示心电专业证据层 |
| `anomaly-center.png` | 异常中心 | 展示 Agent 主动发现能力 |
| `weekly-report.png` | 周报页 | 展示留存型复盘体验 |

## 统一画面要求

- iPhone 15 Pro 竖屏 UI
- 高保真产品设计稿
- 浅色模式
- 中文界面
- 克制健康科技风
- 不出现真实医疗诊断承诺
- 不使用恐吓式红色大警告
- 不出现第三方品牌或水印

## 统一视觉提示

```text
安静可信的智能健康 App，高端 iOS 原生质感，浅雾白背景，深绿和柔和心电红作为点缀，充足留白，精致卡片，清晰健康数据可视化，中文界面，非医疗诊断语气。
```
