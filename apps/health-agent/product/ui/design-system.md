# Health Agent 视觉系统

## 设计目标

Health Agent 的视觉目标是：安静、可信、智能、克制，给用户“今天身体状态被温柔解释清楚”的感觉。

它不是医疗恐吓式 App，也不是数据密集型 Dashboard。第一屏必须像一个每天可打开的健康首页，先给出状态，再引导用户进入洞察。

## 选择的设计方向

最终方向：

```text
Today Health Home + Adaptive Insight Canvas + ECG Evidence Layer
```

含义：

- `Today Health Home`：首页先回答“我今天怎么样”。
- `Adaptive Insight Canvas`：点击问题后，页面由 Agent Schema 组合组件生成。
- `ECG Evidence Layer`：心电作为关键事件证据层，在合适场景插入，而不是默认压住体验。

## 视觉关键词

- 安静
- 可信
- 专业但不冰冷
- 健康但不焦虑
- 智能但不炫技
- 数据清晰
- 留白充足
- 原生 iOS 质感

- `#EEF3F0` 健康浅灰绿

主文字：

- `#18211D` 深墨绿黑
- `#4B5A52` 次级灰绿

品牌主色：

- `#2F7D68` 深健康绿
- `#42B883` 活力绿

心脏与 ECG：

- `#D95F59` 克制心电红
- `#F2B3AC` 柔和心电浅红

睡眠：

- `#6E7BD9` 静谧蓝紫

恢复：

- `#37A779` 恢复绿

运动：

- `#E1A33D` 暖琥珀

警示：

- `#C97A35` 建议关注

## 字体气质

中文界面优先使用系统字体：

- iOS：`SF Pro` / `PingFang SC`
- 标题：半粗，圆润但克制
- 正文：常规字重，行距充足
- 数字：使用等宽或接近等宽的系统数字风格，保证指标可读

## 卡片风格

- 圆角：16-24pt，首页 Hero 可更大
- 阴影：极轻，更多依靠层级、留白和背景区分
- 边框：可使用 `#DDE7E1` 细边框
- 卡片不嵌套卡片，二级内容使用分隔线或浅底块

## 首页结构

首页优先级：

1. 今日状态 Hero
2. Agent 发现
3. 今日模块
4. 继续探索
5. 健康输入框

首页不要堆满图表。图表进入分析页。

## ECG 视觉语言

ECG 不应该像医院仪器界面那样压迫用户。建议：

- 波形使用细线、柔和红色或深绿线
- 信号质量用徽章表达，不用危险图标
- 专业细节默认折叠
- ECG 卡片文案强调“观察点”和“回看当时状态”

## 图表规则

- 一屏最多 2-3 个主图
- 每个图表必须有一句解释
- 趋势图优先展示相对变化和个人基线
- 异常点用温和标记，不用大面积红色
- 图表应支持深色模式扩展，但 MVP 先做浅色

## 组件层级

核心组件：

- 今日状态 Hero
- 洞察按钮
- Agent 发现卡
- 健康模块卡
- 指标变化网格
- 趋势图
- 时间线
- 异常列表
- ECG 事件卡
- ECG 波形
- 数据来源卡
- 下一步问题栏

## 文案规则

推荐：

- 今天恢复偏弱。
- 主要和睡眠减少、运动负荷上升有关。
- 这次 ECG 可作为补充证据。
- 这不是医学诊断，但可以帮助你回看当时状态。

避免：

- 你有风险。
- 你异常了。
- 诊断结果。
- 立即治疗。

## 质量标准

- 首页 3 秒内能读懂今日状态。
- 所有健康结论都有证据入口。
- ECG 能显出专业壁垒，但不制造焦虑。
- 视觉资产应能直接指导 SwiftUI 实现。
- 图片资产保存到 `apps/health-agent/product/ui/` 下。
