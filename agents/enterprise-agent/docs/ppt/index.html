Design Rules

包结构的三条课堂规则。

Rule 01
外部调用顶层入口
学员优先从包入口理解能力，而不是跳进内部文件。

子包入口表达边界

Rule 03
测试写契约

Config Boundary

配置加载分三步：默认值、覆盖、校验。

  • 默认值让本地开发无需先配齐一切。
  • 环境变量覆盖让部署环境可以注入差异。
  • 校验让错误尽早发生，而不是运行中才爆。

Four Layers

模型调用被拆成四层。

  • 消息层：谁说了什么。
  • 请求层：调用哪个模型、带什么参数。
  • 响应层：模型返回什么、用了多少 token。
  • 客户端层：谁负责真正调用。
第 6 章只完成前三层，客户端从第 7 章开始

Async Flow

为什么一开始就用 async？

  • 真实模型调用天然是 I/O。
  • 未来 Agent 循环、工具调用、RAG 检索都会遇到等待。
  • 早期统一异步接口，避免后面从同步迁移。
测试中可以直接用 asyncio.run()，暂不引入 pytest-asyncio

Mock 的价值不是像真，而是稳定。

Client Responsibilities

真实客户端在这一章只承担四件事。

Payload

Retry Budget

重试规则要小而确定。

第 8 章只对 transport 层的超时、连接错误和 transport error 重试；provider 结构错误快速失败。
