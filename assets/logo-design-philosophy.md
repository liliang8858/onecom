# OneCom Logo 设计理念

> 版本 1.0 · 2026-05

---

## 一、核心符号

```
             ●
          ·     ·
        ·         ·
       ·    ┌───   ·
        ·   │      ·
          · │    ·
             ●
```

**主图形：半环 + 游标点阵**

整个标志由三个视觉层次构成：

| 层次 | 元素 | 含义 |
|------|------|------|
| 底层 | 深色半环 `#1A1A2E` | **基础设施** — Monorepo 骨架、CI/CD 管线、签名体系 |
| 上层 | 青绿半环 `#00D4AA` | **业务应用** — iOS App + AI Agent 两大体系 |
| 点缀 | 5 个青绿圆点沿环分布 | **N 个子项目** — 可无限扩展的应用生态 |
| 弧线 | 环内青绿弧线 | **数据/智能流动** — Agent 在系统内的流转路径 |

---

## 二、色彩体系

```text
主色  #1A1A2E  (深海蓝)  → 稳定、信任、基础设施
强调 #00D4AA  (青绿)    → 生命力、智能、增长
文字 #333333  (深灰)    → 可读性优先
副标 #999999  (中灰)    → 辅助信息层级
```

- **深海蓝** — 代表 Monorepo 的"底座"：Fastlane、GitHub Actions、签名系统等基础设施，沉默但坚实
- **青绿** — 代表"上层应用"的生命力：Health Agent、Enterprise Agent 以及未来所有子项目，充满动态

## 三、布局结构

```
                          ┌─────────────────────┐
         ┌── 核心徽标 ──→ │     ◐ (半环图形)     │
         │                └─────────────────────┘
    logo│
    组合│    ┌──────────────────────────────────┐
         └──→│           OneCom                 │  ← 品牌名 (700, 42px)
             │    iOS APPS + AI AGENTS          │  ← 定位语 (300, 13px)
             │                           ●      │  ← 装饰句点
             └──────────────────────────────────┘
```

- 上图形 + 下文标，居中对称
- 图形直径 116px，品牌名距图形底部 120px，呼吸感充足
- 尾部青绿句点收尾，视觉完整

## 四、模组化衍生的优势

OneCom 标志最独特的设计特征是 **模组化**：

### 基础形态
```text
◐   =   ╰ + ╰     (深色底座 + 青绿应用)
```

### 衍生态势
```text
子项目增加 → 只需增加圆点数量
业务线扩展 → 半环可生长为整环
聚焦某领域 → 可用单色变体
```

这意味着 OneCom 的 Logo **不是静态的，而是可生长的**。每添加一个子项目，最直观的体现就是环上的圆点 +1。

## 五、理念关键词

| 关键词 | 解读 |
|--------|------|
| **统一** | 一个仓库管理所有应用，一枚标志承载所有品牌 |
| **生长** | 圆点可增、半环可合，标志随业务共同进化 |
| **双生** | 深环/青环 = iOS/Agents = 基础设施/业务层 |
| **简洁** | 去装饰化，极简几何，符合 Apple 设计审美 |
| **技术感** | 精确计算的半圆、等距分布的点阵，代码即设计 |

## 六、应用场景

| 场景 | 使用方式 |
|------|---------|
| GitHub Repo OG | 完整组合标志（图形 + 文字 + 定位语） |
| iOS App 启动屏 | 简化版：仅图形 + "OneCom" |

| Mac Runner 终端 | ASCII art 半环标识 |
| 社交媒体封面 | 宽幅版：左侧图形，右侧品牌标语 |

## 七、技术约束

- **字体**: Inter (opensource, variable weight, 完美适配屏幕)
- **格式**: SVG (矢量) + PNG (回退)
- **最小尺寸**: favicon 32×32px 时保留圆点计数 3 个
- **安全区域**: 四周保留图形尺寸 20% 以上的留白
- **无障碍**: 深蓝/青绿对比度 4.8:1 (WCAG AA)

---

## 八、与现有品牌资产的关系

现有 `gen_logo.py` 是此设计理念的 **代码化实现**：

- 所有圆点位置经由三角函数计算，保证精确等距
- 半环使用 `stroke-dasharray` 精确截断，数学上完美对半
- SVG 直接生成，无需设计软件，适合 CI 自动化

> **设计即代码，代码即设计。**
> OneCom 的 Logo 诞生于脚本，而非 PhotoShop。
